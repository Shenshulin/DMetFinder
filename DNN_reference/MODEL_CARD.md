## 1. 这个模型做什么

输入一张 **跨样品峰组图**——同一个 feature 在多个样品中的 XIC 叠成的二维图——输出一个
"这是一个可接受的峰"的**模型分数**。

它判断的单位是 **一个峰组（feature）**，不是单个 `(feature, sample)` 峰。
一个峰组里只要有一个样品拖尾，整组的分数就可能被压低，但输出仍是一行。

## 2. 网络与训练

```
Conv2D(32, 3×3, relu, same) → MaxPool(2) → Dropout(0.2)
Conv2D(16, 3×3, relu)       → MaxPool(2) → Dropout(0.2)
Flatten → Dense(64, relu) → Dropout(0.5) → Dense(2, softmax)
```

| 项 | 值 |
|---|---|
| 参数量 | 235,538 |
| 损失 / 优化器 | `categorical_crossentropy` / `nadam` |
| batch / epochs | 128 / 500（早停 patience 10，实际第 40 轮停） |
| 训练 / 校准 / 测试 | 1304 / 740 / 726 张 64×64 图 |
| 训练集类别比 | 652 : 652（1:1） |
| 输入归一化 | **每张图除以自身最大值**，因此所有图的极大值都是 1.0 |

训练数据来自 MassIVE **MSV000084186**，许可 **CC0 1.0**。

## 4. 已知限制（按对使用者的影响排序）

### 4.1 输入必须经过一次无据可依的几何转换 ★最重

作者训练用的是 **64×64**（行 = 64 个保留时间切片，列 = 63 个样品 + 末列窗口标记），
而 DMetFinder 按作者 R 代码原生产出 **31×200**（行 = 30 样品 + 标记行，列 = 200 切片）。
公开材料里**没有任何代码**说明两者如何对应。

本项目做的转换（`pq_dnn_to_model_geometry()`）：时间轴 200→64 按下标压缩；样品轴
**不压缩不插值**，占前 30 列，其余列补 0；标记放末列。往返验证误差为 0，
但**这仍是我们的重建，不是作者的重建**。

后果：所有经转换的行标注 `dnn_applicability = approximate_resampled_input`，
分数**不可与论文的工作点直接互换**。

### 4.2 分数随样品数单调升高 ★会影响结论

同一张干净峰，只改变样品数：

| 样品数 | 3 | 6 | 12 | 20 | 30 |
|---|---|---|---|---|---|
| dnn_score | 0.902 | 0.978 | 0.997 | 0.9997 | 1.000 |

模型见过的是 63 个样品几乎全有信号的图（训练集中位数 63/63）；样品少时图像大片空白，
分数被系统性压低。**同一 feature 在 6 个样品的队列和 30 个样品的队列里分数不可比。**
固定阈值 0.5 在小队列里会更严格，边缘真峰因此更容易被拒。UI 必须提示这一点。

### 4.3 模型看不到绝对强度

输入按图内最大值归一化，绝对丰度在输入阶段就被消掉了。因此：

* 它**不会**因为峰弱就压低分数，也**不能**用来筛"低丰度峰"；
* 任何"模型偏好高强度峰"的说法在这个模型上不成立；
* 实测漏判的真峰集中在**画面更满、峰更宽**的一侧（非零占比分档下漏判率 0.0% → 9.4%），
  不是小峰。

### 4.4 分数不是校准概率

`dnn_score` 是模型对"可接受峰"类的输出，没有做过概率校准，不同种子下同一张图
分数会变动。**不要**做 `p < 0.05` 式的解读，也**不要**当作错误率的估计。

### 4.5 不能替代人看原始图

模型在作者数据上的漏判（真峰被判为差）约 2.8%，且在宽峰/高背景处更集中。
它适合**排序与提示**，不适合**自动删除**。DMetFinder 的设计也据此禁止用
DNN 结果改写 `quality_class`。

### 4.6 训练数据的外部效度未知

作者的独立测试集（`EDML_Test15.mat`、`EDML_RestSetTest15.mat`）在公开数据里**不存在**，
论文用 Cohort 2 做的外部验证无法复现。因此模型在**任何**非作者数据上的表现都没有
经过验证——包括你的数据。详见 `VALIDATION_REPORT.md`。

## 5. 适用与不适用

**适合**

* 给峰组排序，帮助优先复核可疑 feature；
* 作为一条**独立于** peak_cor / SNR / CPC 的旁证（它们看单个峰的形状，DNN 看整组的形状与一致性）；
* 探索性分析中缩小人工复核范围。

**不适合**

* 自动删除峰、自动生成"高质量"标签（DMetFinder 已硬性禁止）；
* 跨数据集、跨样品数比较分数；
* 临床、诊断、法规申报用途；
* 与其它方法的分数量纲相加、加权、排名、合成总分；
* 推断"这个峰是真的"——真峰判定需要化学与生物学证据，模型只做形状判断。

## 8. 维护者需要知道的

* 换权重 = 换模型卡。任何重新训练都必须重跑 `pq_dnn_eval.py`、
  `pq_dnn_diagnostics.py`，并更新本文件第 3、4 节的数字。
* 若将来拿到**带人工标签的 DMetFinder 数据**，正确做法不是调这个模型的阈值，
  而是在 31×200 原生几何上重训——那会消掉 4.1 与 4.2 两条最主要的限制。
  当前没有这样的数据，所以没有做。
* 禁止把 `dnn_prediction == 1` 映射成 `high_quality`。这不是风格问题：
  模型的 true peak 只表示"形状像真峰"，`quality_class` 还要看拖尾、前伸、边界是否清楚，
  两者依据的判据不同。
