# DMetFinder & MSGeter

A comprehensive metabolomics analysis platform built with **R Shiny**, integrating two core tools:

- **DMetFinder**: Differential metabolite screening software for comparing Group A and Group B mass spectrometry data
- **MSGeter**: Mass spectrometry data processing tool providing MS1 feature extraction (Ms1Geter) and MS2 spectrum matching (Ms2Geter)

---

## Features

### DMetFinder — Differential Metabolite Screening

| Feature | Description |
| --- | --- |
| Data Input | Read raw mass spectrometry data for Group A/B (6 columns per sample: Sample(No), RT, RT&m/z, m/z, Intensity) |
| Sample Merging | Merge sample ions by RT&m/z matching within configurable error range |
| Ion Filtering | Filter ions by 50% and 80% presence thresholds across samples |
| Ion Scoring | Score ions based on intensity, count, and relative intensity |
| Isotope Search | Find M+1, M+2, M+3 isotope peaks for each ion |
| Group Comparison | Compare 80% ions of one group against total ions of the other group |
| Differential Summary | Generate differential ion screening summary between Group A and Group B |

**Output files (downloadable as ZIP):**

| File | Description |
| --- | --- |
| `GroupA-50and80PercentIonFilter.xlsx` | Group A 50%/80% ion filter results |
| `GroupA-IonScoring.xlsx` | Group A ion scoring results |
| `GroupA-IsotopeSearch.xlsx` | Group A isotope search results |
| `GroupA-80PercentIonsVsGroupBTotalIons.xlsx` | Group A 80% ions vs Group B total ions comparison |
| `GroupA-GroupB-DifferentialIonSummary.xlsx` | Differential ion summary between Group A and Group B |
| `GroupB-50and80PercentIonFilter.xlsx` | Group B 50%/80% ion filter results |
| `GroupB-IonScoring.xlsx` | Group B ion scoring results |
| `GroupB-IsotopeSearch.xlsx` | Group B isotope search results |
| `GroupB-80PercentIonsVsGroupATotalIons.xlsx` | Group B 80% ions vs Group A total ions comparison |

### MSGeter — Mass Spectrometry Data Processing

#### Ms1Geter

Extracts MS1 and MS2 information from mass spectrometry data files and generates intermediate files for downstream analysis.

**Supported input formats:**

| Format | Reader | Notes |
| --- | --- | --- |
| `.raw` (Thermo) | `rawrr` | Requires Thermo RawFileReader .NET library; MS1 scans are identified by scan type `FTMS - p ESI Full ms [100.0000-1500.0000]` |
| `.mzML` / `.mzXML` | `mzR` | Uses `msLevel` / precursor m/z metadata (no scan-type hardcoding); profile spectra are centroided automatically; ion mode is inferred from the polarity annotation |

**Inputs:**

| Input | Description |
| --- | --- |
| Working Directory | Directory containing `.raw` files and where results will be written |
| Sample Group File | CSV or XLSX format, must contain `Sample` (sample name, matching `.raw` filename) and `Group` (group name) columns |

**Outputs (written to working directory):**

- `MS2_Group_Info.csv` — Summary of all MS2 scan information across samples (scan number, retention time, precursor m/z, etc.)
- `MS2_MGF/` directory — MSP spectrum files for each sample (NAME / PRECURSORMZ / IONMODE / RETENTIONTIME / peak list)
- `Clean_MS1_Data_Group*.xlsx` — Cleaned MS1 data per group (retention time window deduplication, ppm deconvolution, intensity filtering)

#### Ms2Geter

Extracts matched MS2 spectra from MSP files based on a target feature list, generating MSP files for library building.

**Inputs:**

| Input | Description |
| --- | --- |
| `MS2_Group_Info.csv` | Scan information summary exported by Ms1Geter |
| `demo.csv` | Target feature list, must contain `sample` (sample name), `m/z` (precursor m/z), and `RT` (retention time) columns |
| MGF Folder | Directory containing MSP files generated by Ms1Geter |
| Output File Name | Name of the generated MSP file |

**Matching logic:**

- Filter MS2 scan information by sample name
- Filter candidate scans by m/z tolerance (0.01 Da)
- Sort by retention time difference and m/z difference, select the best matching scan
- Extract the spectrum for that scan from the corresponding MSP file

**Output:**

- Target MSP file (written to the selected MGF folder), each spectrum block contains:
  - `NAME` — Sample name + scan number
  - `FEATURE_INFO` — Sample name, RT, m/z traceability information
  - `PRECURSORMZ`, `IONMODE`, `RETENTIONTIME`
  - Peak list (m/z intensity)

- **R** (>= 4.0)
- **R packages**:
  - `shiny`, `shinyWidgets`, `shinyFiles`

## Usage

```r
# Run the application from the project root directory
shiny::runApp()
```

After launching, open your browser and navigate to the Shiny interface (default `http://127.0.0.1:xxxx`).

### DMetFinder Workflow

1. **Data Input** tab: Upload Group A and Group B Excel data files
2. **Parameters** tab: Configure matching error ranges, scoring parameters, and filter thresholds
3. Click **Run Analysis** to run the analysis
4. **Results** tab: Preview results and download all result files as ZIP

### MSGeter Workflow

1. **Ms1Geter** tab: Set working directory → upload sample group file → click `Run Analysis`
2. **Ms2Geter** tab: Upload `MS2_Group_Info.csv` and `demo.csv` → select folder containing MSP files → set output filename → click `Run Extraction`

## Input Data Format

### DMetFinder Raw Data Format

Each sample contains **6 columns**, formatted as follows:

| Column | Description |
| --- | --- |
| Sample(No) | Sample number |
| RT | Retention time |
| RT&m/z | Combined retention time and m/z value |
| m/z | Mass-to-charge ratio |
| Intensity | Ion intensity |
| (6th column) | Empty column (placeholder) |

Multiple samples are arranged sequentially (6 columns per sample). Example data is available in the `demo_data/` directory.

### Example Data

The `demo_data/` directory provides example data files for both groups:

- `demo_data/groupA.xlsx` — Group A example data
- `demo_data/groupB.xlsx` — Group B example data

## Core Algorithm Details

### DMetFinder Analysis Pipeline

1. **Data Reading**: Read raw mass spectrometry data for Group A and Group B
2. **Sample Merging**: Use each sample's ions as reference, match ions from other samples within RT&m/z error range, generate merged data table
3. **Ion Filtering**: Filter ions by 50% and 80% presence thresholds
4. **Ion Scoring**: Combine intensity score, count score, and relative intensity score to calculate total score
5. **Isotope Search**: Search for M+1, M+2, M+3 isotope peaks and calculate intensity ratios
6. **Group Comparison**: Compare 80% ions of one group against total ions of the other group, calculate fold change
7. **Differential Summary**: Generate differential ion screening summary table

### Scoring Mechanism

- **Intensity Score**: Map average ion intensity to scores of 1-10 based on predefined ranges
- **Count Score**: Map ion occurrence count across samples to scores of 1-10 based on predefined ranges
- **Relative Intensity Score**: Map ion percentage relative to maximum intensity to scores of 0.5-10
- **Total Score** = Intensity Score × Count Score × Relative Intensity Score

### Isotope Search

- Theoretical M+1, M+2, M+3 mass differences are 1.00335, 2.0067, 3.01005 Da respectively
- Search for actual isotope peaks within the error range
- Calculate M/M+1, M+1/M+2, M+2/M+3 intensity ratios

## Notes

- Upload file size limit is set to 500 MB (see `shiny.maxRequestSize` in `app.R`)
- Sample names must match MS data filenames (without extension)
- `.raw` files: Ms1Geter is currently written for a specific scan type (`FTMS - p ESI Full ms [100.0000-1500.0000]`); adjust the scan type check in `FeatureGeter_server.R` for other instrument methods
- `.mzML` / `.mzXML` files: no scan-type hardcoding — MS1/MS2 are identified by `msLevel` metadata and precursor m/z is read directly from the file header
